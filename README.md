# Overview

As a software engineer, I'm always looking for ways to strengthen my skills by building projects around things I enjoy. Futbol23 is a Java quiz game about soccer that bundles several different mini-games into one program.

Futbol23 lets the player pick from multiple game modes, each one testing their soccer knowledge in a different way. The program keeps score, gives feedback on answers, and lets the player move between games without restarting.

My goal with this project is to learn Java.
